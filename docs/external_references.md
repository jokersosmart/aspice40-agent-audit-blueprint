# External References Used in Agent Blueprint Design

## VDA QMC — Automotive SPICE
URL: https://vda-qmc.de/en/automotive-spice/

Key facts used: VDA QMC describes Automotive SPICE as a worldwide established standard used by leading OEMs and suppliers to evaluate development processes for software-based systems in and around vehicles. It describes the assessment model as having a process dimension and a capability dimension. It states that the capability of each individual process in scope is evaluated and that there is no consolidated level for a project or company.

## VDA QMC — Automotive SPICE Publications
URL: https://vda-qmc.de/en/automotive-spice/automotive-spice-veroeffentlichungen/

Key facts used: The page lists Automotive SPICE PAM 4.0 as version 4.0, December 2023, and provides the English PDF. It also notes that translations are for information and that the English version is authoritative in case of doubt.

## intacs — Training Center
URL: https://intacs.info/training-center

Key facts used: The intacs training architecture for Automotive SPICE 4.0 includes Process Expert, Provisional Assessor and Competent Assessor paths. Process Expert training supports internal projects and improvement programs; Provisional Assessor training supports co-assessor work; Competent Assessor training supports leading official assessments. The same page lists Hardware SPICE, Machine Learning SPICE and Cybersecurity SPICE as related extensions or training areas.

## DNV — Automotive SPICE Process Assessment
URL: https://www.dnv.com/services/automotive-spice-aspice-process-assessment/

Key facts used: DNV describes ASPICE assessment as evaluating software and system development lifecycle capability, identifying gaps, providing evidence-based improvement recommendations, improving supplier credibility with OEMs and supporting risk reduction and better project outcomes.

## Usage boundary

These external pages are supporting references for architecture context. Normative Agent conclusions must use the approved user-provided standard sources and direct verbatim citations at runtime. A URL or secondary source must not substitute for the complete approved clause or table-row quotation.
